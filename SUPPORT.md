# Support

Wissenswerk is currently a branch-first consolidation project.

Use GitHub issues for:

- bugs in the generic CLI,
- RagPrep import contract problems,
- retrieval/provider configuration issues,
- documentation gaps,
- public export readiness blockers.

Do not use public issues for:

- private corpora,
- API keys,
- Discord bot tokens,
- database URLs,
- unpublished tenant material.

For security-sensitive reports, follow [SECURITY.md](SECURITY.md).
